# Security Skill

Treat browser input, query parameters, cookies, request bodies, headers, and uploads as untrusted.

Check authentication, authorization, session handling, validation, XSS, CSRF where applicable, injection risks, rate limiting, secret handling, error leakage, IDOR, and client/server boundaries.

Never trust client price, subtotal, total, stock, discount, or order status.
